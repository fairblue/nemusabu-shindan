# ねむサブ診断

契約中のサブスクを自己申告で選ぶだけで、「眠っている（使っていないのに払っている）金額」とサブスクの健全度を約30秒で診断する小さなWebツールです。アカウント連携は一切しません。入力内容は保存・送信されません。

## 機能
- サブスクカタログ34件（8カテゴリ）＋カスタム入力（月額/年額対応）
- 月額・年額合計、眠り金額の推定（利用頻度ベース）
- 健全度スコア（S〜D）
- カテゴリ別の内訳（表＋グラフ）
- 解約・見直し候補リスト（節約余地つき）
- X共有テキストの自動生成

## 実行方法
```bash
pip install -r requirements.txt
streamlit run app.py
```

## テスト
```bash
python3 test_logic.py
```

## 構成
- `app.py` — Streamlit UI
- `logic.py` — カタログと計算ロジック（UIから分離、単体テスト可能）
- `test_logic.py` — 計算ロジックの検証
- `NOTE-DRAFT.md` / `X-DRAFT.md` — 公開用ドラフト（未投稿）

## 注意
- 金額は各サービスの一般的なプランの税込目安で、実際の請求額と異なる場合があります。
- 眠り金額は利用頻度からの推定値です。
